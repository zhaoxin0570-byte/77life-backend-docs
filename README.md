# 七七生活后台操作文档系统

将后台各模块的操作流程整理为可在线浏览的文档系统，按「模块 → 章节 → 步骤」三级展示（每步含菜单路径、操作说明、注意事项与操作截图，截图可点击放大）。

## 功能特性

- **多模块架构**：一个模块一个文件，后续新模块随时可插拔加入
- **后台一致风格**：左侧分类导航 + 白色侧边栏 + 浅灰内容区，与七七生活后台（Element Plus）视觉规范一致；无顶部导航，便于以 iframe 方式嵌入后台
- **工作台**：首页统计已上线模块、章节、步骤、截图数量，并展示全部模块的文档进度表
- **章节浏览**：左侧按一级分类（操作流程 / 功能说明 / 参考资料 / 框架待补）→「模块 → 章节」三级分类（模块可折叠，当前模块自动展开），章节页按步骤展示操作说明。一级分类规则：端到端完整操作流程归「操作流程」（status: active 自动进入）；分功能说明文档归「功能说明」；平台模块分析截图资料归「参考资料」；占位模块归「框架待补」。分组规则集中在 `src/docs/index.js` 的 `MODULE_GROUP_OVERRIDES`
- **截图对照**：每步配套操作截图，默认限宽显示，点击弹出原图
- **操作要点**：关键规则与注意事项高亮提示
- **可部署**：hash 路由 + 纯静态构建（`npm run build`），产物可放入任意子目录或以后台 iframe 方式嵌入

## 如何添加新模块（重要）

整个后台的文档都往这个系统里加，步骤只有两步：

1. **新建模块文件**：复制 `src/docs/growth.js` 为 `src/docs/你的模块.js`（如 `order.js`），修改开头的默认导出：

```js
export default {
  id: 'order',                 // 模块 ID（URL 用，唯一）
  name: '订单管理',            // 模块名称
  summary: '订单查询、发货、退款...', // 一句话简介
  status: 'active',            // active=已上线 / planned=待完善
  chapters: [                  // 章节数组
    {
      id: 'ch1',               // 章节 ID（URL 用，模块内唯一）
      title: '订单查询',
      summary: '按状态、时间、关键词筛选订单',
      group: '订单中心',        // 可选：三级导航分组名（如后台菜单有二级）。
                              // 同组名的章节在侧边栏/目录中归为一组；
                              // 不写则平铺展示（两级行为）
      steps: [                 // 步骤数组
        {
          id: 'ch1-s1',
          title: '按条件查询订单',
          menu: '订单 → 订单管理',   // 菜单路径
          desc: '操作说明文字……',
          points: ['注意事项 1'],     // 可省略
          images: [img01]            // 截图 import，可省略
        }
      ]
    }
  ]
}
```

> **三级导航**：当后台菜单存在二级（如「财务 → 成长值 → 配置」）时，给章节加 `group: '成长值'` 即可自动生成「模块 → 分组 → 章节」三级侧边栏与目录，无需改其他代码。示例见 `src/docs/finance.js` 的「成长值」分组。

2. **注册模块**：打开 `src/docs/index.js`，`import order from './order'` 并加入 `modules` 数组（顺序即展示顺序）；同时把 `plannedModules` 里对应的占位项删掉。

保存后刷新页面即可看到新模块，无需改其他任何代码。

> 截图放置：把图片复制到 `src/assets/docs/`，在模块文件顶部 `import img01 from '@/assets/docs/图片名.png'` 后引用。

## 技术栈

- Vue 3 + Vue Router + Vite
- 无后端依赖：文档内容在 `src/docs/`，截图在 `src/assets/docs/`

## 本地运行

**方式一：一键启动（推荐）**

双击项目根目录的 `一键启动.bat`：
- 服务已在运行 → 直接打开浏览器
- 首次运行 → 自动安装依赖 → 启动服务并打开浏览器
- 停止服务：关闭黑色命令行窗口或按 `Ctrl+C`

**方式二：命令行**

```bash
npm install
npm run dev
```

启动后浏览器访问 http://localhost:5173

## 部署到七七生活后台

本文档系统为纯前端静态应用（无后端依赖），使用 hash 路由，构建产物可放到任意路径：

```bash
npm run build   # 产物在 dist/ 目录
```

部署方式（二选一）：

1. **iframe 嵌入**：把 `dist/` 放到后台静态资源目录（如 `/docs/`），在后台页面中嵌入
   `<iframe src="/docs/index.html" style="width:100%;height:100%;border:none;"></iframe>`
2. **路由合并**：将本文档的路由表并入后台路由体系（页签/侧边栏配置在 `src/views/DocLayout.vue`）

嵌入后如需与后台统一账号体系（读取后台登录态），在 `src/main.js` 中接入后台的 token 获取逻辑即可。
